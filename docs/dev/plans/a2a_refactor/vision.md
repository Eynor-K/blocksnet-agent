# A2A-агент + MCP raw tools — рефакторинг blocksnet-agent

Переход от «один MCP-tool с агентом внутри» к двум сервисам:

- **A2A-агент** — рассуждающий слой (PTR, RAG, гипотезы, инварианты, LLM)
- **MCP-server** — тонкий фасад над детерминированными инструментами, без LLM

Оба используют **общую фабрику инструментов** и работают независимо друг
от друга: агент исполняет инструменты у себя в процессе, MCP — у себя,
в рамках сессии (почему именно так — [../../decisions/open_questions.md](../../decisions/open_questions.md) Q6).

## Что решено

| Вопрос | Решение |
|---|---|
| A2A-библиотека | `a2a-sdk`, версия пиниться после обязательного спайка |
| Skills | Два: `run_pipeline` + `analyze_urban_question` (обёртка над ним же) |
| Репозиторий | Моно-репо, два Dockerfile, extras в `pyproject.toml` |
| Состояние инструментов в MCP | Явные сессии `session_id` + TTL/LRU |
| Формат выхода инструментов | Текст без изменений + конверт; JSON Schema только на вход |
| Топология | Агент **не** ходит в MCP — оба поверх общей фабрики |
| `analyze_urban_question` в MCP | Остаётся под флагом, deprecated до v2.1 |

Требуют явного подтверждения Игоря: **Q6** и **Q7** (меняют объём работ).
