## Ключевые решения, определившие форму плана

1. **Агент не вызывает MCP** (Q6). Инструменты пишут в `state`, который
   читает постобработка агента (overlay, гипотезы, confidence). Граница
   процесса рвёт это тихо. Оба сервиса — равноправные потребители
   `make_tools()`. Сетевое разделение отложено
   ([../../deferred/a2a_refactor_deferred.md](../../deferred/a2a_refactor_deferred.md) D1).
2. **MCP получает модель сессий** (Q4). Без `session_id` половина каталога
   отвечает «Кэш пуст».
3. **Экспонируется 32 инструмента**, не 33: `submit_answer` — терминальный
   инструмент агентского цикла. Число в коде не хардкодится.
4. **Выход инструментов остаётся текстом** (Q5). JSON Schema — только на вход.
5. **`analyze_urban_question` остаётся в MCP как deprecated** (Q7) — от него
   зависят 6 мест в тестах, скриптах и примерах.

## Риски

| Риск | Вероятность | Митигация |
|---|---|---|
| Тихий регресс качества ответов при разделении | **высокая, если нарушить Q6** | Агент исполняет tools in-process; финальная сверка `recommendation_blocks`/`confidence` до и после ([checklist.md](checklist.md)) |
| `a2a-sdk` нестабилен или не ставится | средняя | Спайк на шаге 00 с exit-критерием; альтернатива — свой JSON-RPC (+3–5 д), заменяется один пакет |
| Утечка памяти в MCP (GeoDataFrame в сессиях) | средняя | TTL + LRU + явный `state.clear()` в `close()` |
| Конкурентные задачи A2A глушат друг друга | **высокая без шага 04** | Стоп-флаг переносится в `RunContext` |
| Ломаются существующие потребители MCP | низкая | Инструмент сохранён под флагом; 6 мест перечислены поимённо |
| Path traversal через `scenario_id` | средняя | Валидация + `is_relative_to`, тесты обязательны (шаг 06) |
| Каталог документации протухает | средняя | Каталог генерируется, актуальность проверяется тестом |

## Критерии завершения

Кратко:

- [ ] MCP экспонирует весь каталог (сверка тестом, не числом) и стартует
      без `CHAT_URL`/`API_KEY`

- [ ] `pytest` не хуже baseline, новые тесты зелёные
- [ ] Документация и контракт v2 обновлены
